# Molana-Poetry — نسخه یکپارچه با متن‌های داخلی

این نسخه بر اساس سایت موجود شما و فایل `ganjoor.s3db` ساخته شده است.

## چه چیزی اضافه شده؟
- متن کامل داده‌های مولانا از فایل SQLite داخلی استخراج و به JSONهای محلی تبدیل شده است.
- **۶٬۳۲۹ متن** و حدود **۱۳۳٬۰۸۴ سطر/بیت** در چهار مجموعه قرار گرفته است.
- دیوان شمس: غزلیات، رباعیات، ترجیعات، مستدرکات
- مثنوی معنوی: دفتر اول تا ششم
- فیه ما فیه
- مجالس سبعه: هفت مجلس
- جستجوی سریع در عنوان همه متن‌ها
- نمایش شعر داخل خود سایت
- کپی و چاپ
- حالت تاریک/روشن
- بدون نیاز به PHP، Python، Node یا دیتابیس در GitHub Pages

## ساختار
- `index.html` — سایت اصلی
- `style.css` — طراحی
- `script.js` — منطق سایت
- `data/catalog.json` — اطلاعات مجموعه‌ها
- `data/search-index.json` — فهرست جستجو
- `data/shams.json` — متن‌های دیوان شمس
- `data/masnavi.json` — شش دفتر مثنوی
- `data/fihi.json` — فیه ما فیه
- `data/majales.json` — مجالس سبعه

## نکته مهم برای GitHub Pages
تمام فایل‌های این پوشه را **با همان ساختار پوشه‌ها** داخل Repository قرار دهید. پوشه `data` را حذف یا تغییرنام ندهید.

## منبع داده
داده اولیه از `ganjoor.s3db` ارسالی شما استخراج شده است. پیش از انتشار عمومی، شرایط و مجوز/نحوه انتساب داده‌های Ganjoor را بررسی و متن انتساب موجود در `LICENSE-DATA-NOTE.txt` را نگه دارید.

## اجرای محلی
برای تست بهتر، Repository را با GitHub Pages اجرا کنید یا از یک Local Web Server استفاده کنید. بازکردن مستقیم `index.html` با `file://` ممکن است به دلیل محدودیت مرورگر در `fetch` فایل‌های JSON کار نکند.
